# Jazz

Небольшой сайт о джазе. Чтобы открыть его, запустите `index.html` в браузере.

## Структура проекта

- `index.html` — основная страница сайта.
- `img/` — изображения и графика.
- `style/` — стили сайта.
- `scripts/` — JavaScript для интерактивных элементов.
- `archive/` — сохранённая прежняя копия страницы.
